# ⚔️ VibeGame — Пепел и Кровь

2D экшен-RPG с элементами стратегии и выживания на движке **Godot 4**, вдохновлённая атмосферой **Dark Souls** и двухмерным исследованием мира в духе **Terraria**.

---

## 🔥 Основные особенности

- **Атмосфера тёмного фэнтези**: мрачное оформление интерфейса, частицы пепла и костра, процедурные и записанные звуковые эффекты.
- **6 игровых классов** с уникальными характеристиками, лором и пиксель-арт анимациями:
  - 🛡️ **Страж Пепла** — тяжелобронированный рыцарь со щитом и высокой живучестью.
  - 🩸 **Багровый Палач** — падший рыцарь, полагающийся на стремительный натиск.
  - 🔥 **Пиромант-Изгнанник** — мастер меча и первородного пламени.
  - ⚡ **Жрица Грома** — самый быстрый класс с высоким запасом выносливости.
  - 🌑 **Странник Бездны** — тёмный мистик с посохом и эфирными ударами.
  - ❄️ **Северный Авангард** — сбалансированный мечник морозных земель.
- **Боевая система и движение**:
  - Чередование атак в комбо (`Attack 1` / `Attack 2`) с тратой и регенерацией выносливости (Stamina).
  - 6 визуальных стилей рассечения клинком (переключение в реальном времени на клавиши `1`–`6`).
  - Перекат (Dodge Roll) и приседание с уменьшением хитбокса.
- **Система костров и сохранений**:
  - Отдых у костра восстанавливает здоровье и выносливость, а также сохраняет прогресс и выбранный класс (`user://savegame.save`).

---

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **`A` / `D`** или **`←` / `→`** | Движение влево / вправо |
| **`S`** или **`↓`** | Приседание (уменьшает хитбокс, замедляет шаг) |
| **`Пробел`** / **`W`** / **`↑`** | Прыжок |
| **`Shift`** | Перекат (Dodge Roll, расходует выносливость) |
| **`ЛКМ`** или **`J`** | Удар оружием (расходует выносливость) |
| **`1` – `6`** | Смена стихийного эффекта удара |
| **`E`** | Отдохнуть у костра (восстановление и сохранение) |
| **`Esc`** | Сохранить и выйти в главное меню |

## 🚀 Как развернуть и запустить проект у себя

### 1. Требования
- Скачайте и установите **Godot Engine 4.x** (рекомендуется версия **4.3+** или **4.7**, стандартная версия без .NET):
  👉 [Официальный сайт Godot Engine](https://godotengine.org/download)
- Никаких дополнительных пакетов, `pip` или виртуальных окружений не требуется — всё необходимое уже включено в проект и сам движок.

### 2. Клонирование репозитория
Откройте терминал (PowerShell / Git Bash) и выполните:

```bash
git clone https://github.com/ArtemPribytkov/vibegame.git
cd vibegame
```

### 3. Импорт и запуск в Godot
1. Запустите **Godot Engine**.
2. В окне **Менеджера проектов** нажмите кнопку **«Импорт» (Import)**.
3. Укажите путь к склонированной папке `vibegame` и выберите файл **`project.godot`**.
4. Нажмите **«Импортировать и изменить» (Import & Edit)**.
5. После открытия редактора нажмите клавишу **`F5`** (или кнопку ▶ **Запустить проект** в правом верхнем углу), чтобы начать игру.

## 📁 Структура проекта

```text
vibegame/
├── assets/
│   ├── audio/          # Звуковые эффекты интерфейса
│   ├── characters/     # Спрайт-листы 6 классов персонажей
│   ├── effects/        # Покадровые анимации и иконки ударов мечом
│   ├── sprites/        # Спрайты окружения и костра
│   └── ui/             # Эмблемы и иконки интерфейса
├── scenes/
│   ├── entities/       # Сцена игрока (player.tscn)
│   ├── ui/             # Главное меню и экран выбора класса
│   └── world/          # Игровой мир (game_world.tscn)
├── scripts/
│   ├── autoload/       # Глобальные синглтоны (UISoundManager)
│   ├── data/           # Данные и характеристики классов (character_classes.gd)
│   ├── entities/       # Логика игрока, физики, перекатов и боя
│   ├── ui/             # Скрипты меню
│   └── world/          # Логика мира, костра и сохранений
└── project.godot       # Конфигурационный файл проекта Godot
```
